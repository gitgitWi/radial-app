# Radial

Radial is an Agentic Task & Terminal Manager designed to maximize developer productivity. It provides a central hub for managing autonomous coding agents and terminal sessions with a local-first, sync-augmented architecture.

## Core Concepts

- **Omni-Input Floating Window**: Quick access to task creation and agent triggering.
- **Git Worktree Isolation**: Run multiple agents in parallel without file system conflicts.
- **Background Session Management**: Persistent tmux-based agent sessions that survive app restarts.
- **Local-first Sync**: Multi-client support (Mac, Web, Mobile) with Turso/libSQL synchronization.
